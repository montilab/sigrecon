# Calculate Jaccard Similarity for Multiple Pairs of Sets

Calculate Jaccard Similarity for Multiple Pairs of Sets

## Usage

``` r
v.jaccard(sigs1, sigs2)
```

## Arguments

- sigs1:

  A named list of genesets (vectors)

- sigs2:

  A named list of genesets (vectors)

## Value

A vector of Jaccard similarity scores
